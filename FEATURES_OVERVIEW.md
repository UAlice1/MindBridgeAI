## 🔒 Privacy Architecture

### Data Flow
```
User Device (Browser)
        ↓
   LocalStorage
   - Anonymous Hash
   - Conversations
   - Preferences
        ↓
   (No Server Storage)
        ↓
   AI API (Groq)
   - Processes message
   - Returns response
   - No data retention
        ↓
   Response displayed
        ↓
   Stored locally only
```

### What Gets Stored Where
```
LOCAL (Your Browser):
✅ Anonymous hash ID
✅ Conversation history
✅ Language preference
✅ Selected mode

NOWHERE (Never Stored):
❌ Your real name
❌ Email/phone
❌ IP address
❌ Location data
❌ Any PII
```
